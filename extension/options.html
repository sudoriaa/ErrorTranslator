只交付译文

每批多个元素合并到一个请求，严格校验 JSON 段落编号与纯译文。原文 hello world 只交付「你好世界」。异常输出自动纠正重试，仍不合格则保留原文；开启「译文自检」可增加一次独立复核。

请求节奏与超时

例如 5 并发 × 每批 16 段：最多同时处理 5 个批次。所有页面共用并发上限；长文本按长度进一步拆批。百度保持逐段串行限速。超时从请求开始计时，不含排队等待；保存后下次翻译、模型获取或连接测试生效。

开始使用

  1. 在「翻译供应商」中连接至少一个服务，填写官方 API 密钥并保存。
  2. 打开普通网页，点击 Chrome 工具栏中的艾拉图标。
  3. 选择目标语言、供应商和阅读方式，点击「翻译当前网页」。
  4. 随时切换模式，或点击「恢复原文」还原页面。

翻译与数据

注释、代码块、代码编辑器、表单和可编辑区域始终跳过；链接和已有 DOM 保留。仅翻译可见的文字，不翻译图片中的文字。支持开放 Shadow DOM 与同源 iframe；跨域 iframe、浏览器内部页面、Chrome 商店和内置 PDF 阅读器无法翻译。

源语言「自动检测」交由所选供应商逐段识别，可用于混合语言网页。悬停模式先分组翻译整页，鼠标移入后在原位置替换成译文，移开 2 秒后恢复原文。

密钥只保存在此浏览器的扩展本地存储中，不通过 Chrome 同步。网页无法读取密钥。翻译缓存只驻留后台内存，后台休眠或浏览器关闭后清空。你的网页文本及开启的 AI 上下文会发送给所选供应商；不要将敏感网页交给不信任的服务。

配置备份

导出包含供应商地址、模型与阅读偏好，不包含 API Key 或百度 APP ID。导入后需要重新填写凭据并授权 API 地址。
